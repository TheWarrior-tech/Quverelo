## Mobbin pattern notes
—— 18 concrete observations ——

1) Sidebar widths and the no-border panel split (Framer dark homepage, FLORA, Runway, Frame.io)
Pro web apps separate a left navigation column from the main area by a one-stop background shift, not a border: Framer sidebar ~#141414 against main ~#1E1E1E; FLORA and Runway use the same trick. The sidebar is a fixed narrow width (Framer ~348px with a visible workspace header; Frame.io's collapsed icon rail is ~80px; FLORA/Runway grouped sidebars land in the ~260–320px range). Inner padding is generous — Framer content band x≈102–376 inside a 348px column, ~37px each side. Takeaway for Quvrelo: prefer a tone-shift divider over a 1px hairline between the tool rail and the canvas; reserve hairlines for controls inside a panel (section dividers, list separators).

2) Navigation row rhythm and active state (Framer, FLORA, Runway)
Framer and Runway both use a 44px vertical rhythm for nav rows (Framer: y 489 → 533 for Recent/Archived; Runway grouped items sit on the same ~44px grid). The icon sits ~35px to the left of the label (Framer icons at x≈121, labels at x≈156). The active row signals selection purely by recoloring the icon AND the label to the accent (Framer blue ~#3B8CF0) — there is NO background highlight pill. Hover, by contrast, uses a background fill change. Takeaway: make selection a color swap on both glyph and text, keep hover as a surface tint, and stay on a 44px row height so a 20px icon + 16/16 internal padding fits without crowding.

3) Accent colour used sparingly as the only selection/primary hue (Framer, FLORA, Runway, Frame.io)
Across every app, the accent is deployed at only four roles: (a) the active nav row's icon+label, (b) the one primary action button ("Upgrade" on Framer, "New Project"/"+ New" on Framer and Runway, "Export" on Descript is dark-but-prominent), (c) avatars/badges for the current user, and (d) a few inline links. Secondary buttons and most controls stay in surface gray. Framer's "+ New" is a blue 84×36 button, ~8px radius, sitting in an otherwise gray toolbar. Takeaway for Quvrelo's tokens: pick a single restrained accent and allow it in only those four roles; buttons, toggles and fields in panels must be neutral.

4) Corner radii hierarchy — two values, not a gradient of radii (Framer, FLORA Credits Dashboard, Descript)
Cards, panels and the Upgrade card all land on ~12px (Framer feature cards 447×311 @ ~12px; FLORA Credits stat card and modal card @ ~12px; Descript's right-side AI panel cards follow suit). Controls inside panels (buttons, chips, avatars, small inputs) sit at ~8px — Framer "+ New" @ 8px, Framer avatar @ 8px rounded square, FLORA active-pill uses ~8px. Mobbin's own chrome reinforces this discipline: chip tags are rounded-8, the secondary Copy button is rounded-full pill but the surrounding UI is 8/12. Takeaway: expose exactly two radii in the tokens — 8 for controls, 12 for containers — and nothing in between.

5) Card sizing and grid gaps on homepages (Framer, Runway, FLORA workspace)
Framer's homepage uses a strict 2-column card grid: each card ~447px wide with a 50px gap, both in the "Get Started" feature row and the project grid below. Runway's project grid is a denser multi-column masonry with smaller ~240–280px cards. FLORA's workspace is the same wide 2-up with generous spacing. Takeaway: the studio homepages should use 448/447-width cards on an 8px grid (447 = 55.875 × 8, so the gap is the variable) — standardise on either 448 cards + 48 gap, or keep 447 + 50 if the app favours 50px major spacing.

6) Properties / data panels — label-over-value metric strip (FLORA Credits Dashboard)
FLORA's "People & Credits" panel opens with a single bordered card containing a 4-column stat strip. Columns are separated by thin vertical dividers, each cell has a muted small label stacked above a larger bold value, and a custom unit glyph (credit icon) is inline with the number. A footer row, separated by a single horizontal divider, carries an upsell line + secondary "Add credits" (dark fill) + primary "Set up Autopay" (white fill on dark). Takeaway: for Quvrelo's inspector panels, lead with a label-over-value metric strip; put secondary/primary CTA pairs in a divider-separated footer; never stack four metrics vertically — lay them out in a row at readable widths.

7) Members / layers table — chip-with-count + search + primary action header (FLORA Credits)
The Members table header is a single row: on the left a "Members 1" tab/chip that embeds the row count as a badge, on the right a search icon and a white Invite primary button. Columns are Person | Usage | Permissions | actions. The single row beneath has generous vertical empty space, a person avatar + name + muted email stack, and an "Admin ▾" permissions dropdown that is grayed out (disabled look, not removed). Takeaway: layer/lower lists should mirror this — a count-badged scope chip, a search, and one primary button; permissions/lock states must render disabled, not vanish.

8) Settings/preferences as a grouped left-nav modal over a blurred backdrop (FLORA Credits)
FLORA opens its settings as a modal (not a side-sheet) with a blurred backdrop and a close × top-right. The left nav inside the modal is grouped: Account (Profile, Preferences), Workspace (Settings, People & Credits, Billing with an external ↗ icon), then a divider, then Plans & Pricing. The active item "People & Credits" is highlighted with a lighter pill background. Takeaway: Quvrelo's Preferences should be a modal with a blurred backdrop, a left grouped nav with section headers and dividers, and an active pill (not an active accent stroke).

9) Empty / welcome canvas — gesture teach + pill quick-starts (FLORA Blank Canvas)
On a blank document FLORA shows a black infinite canvas with a faint dot grid. A low-contrast centered prompt teaches the primary gesture: "Double-click anywhere to create a new Block, or start with…" where "Double-click" is set as an inline key chip with a small cursor/sparkle icon. Below it is a horizontal row of pill-shaped quick-start actions: "Describe an Image", "Combine ideas", "Make a video from an image", "Explore Flows", plus a ⋯ overflow. A persistent white circular "+" at the top of the floating left tool rail is the alternate primary create. Takeaway: the welcome state must (a) teach the core gesture in a single sentence with the verb as a chip, (b) offer 4–5 pill starter actions, and (c) never replace the persistent tool rail.

10) Floating vertical tool rail beside the canvas (FLORA Blank Canvas, Descript)
FLORA's empty canvas carries a floating vertical tool rail on the left with a large white circular "+" at the top as the primary create, then icon buttons for shapes/assets, history, flows/templates, brush/style, comments, help, and a purple user avatar pinned at the bottom. Descript uses the same pattern on the far right of its editor — a vertical rail labelled Project, AI Tools, Properties, Elements, Captions, Media, with the Underlord assistant pinned at the bottom. Both rails are icon-only with the active/expanding panel opening inline, not in a separate window. Takeaway: the studio tool rail must be icon-only, ~48px wide, with the primary action at the top and a user/assistant pinned at the bottom; avoid text labels unless the panel is expanded.

11) Timeline and transport as a stacked strip with a single accent playhead (Descript)
Descript's bottom timeline stacks in this order: transport row (skip back/forward, chapters, timecode "00:12.5 / 01:44.9", Record, pause, 1x speed, Split), a zoom row ("–" 124% "+" with a selection-tool dropdown and list/grid layout toggles), a time ruler, then tracks. The playhead is a single thin blue line at ~0:12.5 — the only accent in the timeline. Tracks are color-coded by type (layer tracks pink and tan, transcript text track, audio waveform). Scene thumbnails are a strip above layers. Inline gap durations ("1.0s", "0.9s") sit between transcript segments. Takeaway: for Quvrelo's Photo/Vector/Layout timelines or history stacks, use one thin accent playhead, color-code track types with muted pastels, and expose time/length numerals inline.

12) Search as a centered command-bar overlay (Frame.io, Runway)
Frame.io's search opens as a wide centered input reading "Search for assets, folders, and projects" that dims everything else — a Spotlight / ⌘K style overlay rather than a sidebar search box. Runway exposes the same pattern in its top bar: "Search for tools, assets and projects" as the top-level search field next to a ? help icon and avatar. Takeaway: the global search must be a centered overlay that dims the canvas, not an inline field, and it must search both tools and assets.

13) Segmented grid/list toggle and small toolbar controls (Framer, Runway, Descript)
Framer's project toolbar ends with a grid/list segmented toggle ~84×36 inside a dark gray container; the active segment is a lighter tile, no accent colour. Runway shows the same grid toggle next to a "Date updated" sort. Descript's timeline has a list-vs-grid layout toggle at the same scale. Across the three, segmented controls are pill-shaped containers with the active state expressed as a filled tile inside, not as an outline or accent. Takeaway: draw segmented controls as a contained pill where the active segment is a contrasting fill; keep them out of the accent palette.

14) Dialogs / modals — rounded card on a blurred backdrop with a divider-separated footer (FLORA, Front, Krea AI, Jasper — Mobbin Dialog roundup)
The Dialog roundup (/explore/web/ui-elements/dialog) surfaces FLORA, Front's "Setup Guide Modal", Jasper's dialog, Krea AI's "Updated Image Results", and a Databricks "Workspace Selection" modal. All share: a rounded-12 card, a blurred/dimmed backdrop, sectioned content, and an action footer separated from the body by a single hairline. Front's setup guide adds a Tab + Progress Indicator strip at the top of the dialog (tags: Tab, Progress Indicator, Guided Tour & Tutorial, Adding & Creating). Takeaway: dialogs must use the same 12px radius as cards, a single hairline above the button footer, and a blurred backdrop — never a solid black overlay at high opacity.

15) Toolbar icon treatment — uniform small glyphs, no stroke-weight mixing (Frame.io icon rail, FLORA rail, Descript timeline icons)
Frame.io's collapsed rail draws Home, Search, Notifications, Uploads, Help, Tips and Keyboard-shortcuts as uniform small glyphs vertically stacked with a clear spacer between the navigation group (top) and the utility group (bottom). FLORA's floating rail and Descript's transport icons (skip, Record, pause, 1x, Split) are drawn at the same apparent size and visual weight — there is no switch between filled and outlined within one rail. The icons read as sitting on a single grid (likely 16×16 or 20×20) with consistent corner treatment. Takeaway: Quvrelo's icon set must be drawn on one grid with one stroke weight per context; do not mix filled tool icons with outlined panel icons in the same rail.

16) Hairline and divider treatment — dividers sit BELOW content, colour is one stop above the background (Framer, FLORA, Descript)
Framer draws a hairline under the search/sort row at y≈1088 (the search bar top is ~1051, so the divider is ~37px below content, not hugging it). FLORA's Credits panel uses thin row dividers with deliberate empty space below the lone row, and vertical dividers between the four stat columns at the same tone. Descript's timeline separates the transport row from the zoom row and the ruler with no extra padding — but those are functional separators inside a dense strip. Pattern: structural dividers between sections carry a small gap above them; tight separators inside a strip touch the content. Takeaway: define two divider tokens — a "section" divider with an 8–12px top gap, and a "compact" divider with zero gap for inside-strip use.

17) Typography tiers and tabular-feel numerals (Framer, FLORA, Descript timecode)
Every app uses a strict three-tier text hierarchy: white/primary for headings and selected text, a ~#A0A0A0 mid-gray for body/labels, and a dimmer gray for placeholders and disabled text. Framer's heading ("Get Started") is ~24px bold; card titles are white bold; subtitles are semi-transparent white at a smaller size. FLORA's stat labels are the mid-gray in a smaller size and the values are bolder at the same size. Descript's timecode "00:12.5 / 01:44.9" and zoom "124%" render in a fixed-width / tabular-feel style so digits don't jiggle. Takeaway: the type scale must separate three text tiers and must use a tabular-nums feature for every timecode, percentage, dimension and numeric input.

18) Announcements, badges and the "Beta" treatment (Frame.io, Descript, Runway)
Frame.io shows a dismissible announcement banner "Welcome to Version 4" with a gradient background, a "Choose Project Template" CTA and a close × — it sits in the main content flow, not in the chrome. Runway's sidebar labels the "AI Training" nav item with a small numeric badge "1" (a count, not a dot). Descript labels its right AI panel "Underlord" with a "Beta" tag. These are the only places a gradient appears in otherwise neutral UIs (and only on a marketing-style card or a transient banner, never on controls). Takeaway: gradients are allowed only on hero feature cards and transient announcement banners; controls, panels, rails and the canvas chrome must be flat. Badge treatment should be a small rounded count pill, not a red dot.
